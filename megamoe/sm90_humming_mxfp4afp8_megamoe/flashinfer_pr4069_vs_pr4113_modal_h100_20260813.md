# FlashInfer PR4069 Push vs PR4113 Pull：Modal H100 EP8 对照

## 结论

- 在现有两组 Modal 单机 8×H100 测量中，PR4069 的报告延迟在 22/22 个 workload 点均低于 PR4113。
- `PR4113 / PR4069` 延迟比：Flash 为 1.199–1.745×，Pro 为 1.178–1.968×；差距在 `M>=256` 后明显扩大。
- 这不是严格的 push/pull style A/B：PR4069 测量 `stage_inputs(...) + compute(...)`，PR4113 仅测量 `compute(...)`，而且 capacity、seed 和 observation 数也不一致。

## 解读

- 小 workload（`M<=128`）：两组数值更接近，PR4113 报告延迟高 1.178–1.321×。
- 中大 workload（`M>=256`）：PR4113 报告延迟高 1.455–1.968×，Pro 的差距总体大于 Flash。
- 即使 PR4113 的计时范围更窄，其现有绝对值仍高于 PR4069；这说明当前 PR4069 配置在这组 H100 workload 上更有优势，但不能单独归因于 push style。
- 要回答“push 还是 pull 更快”，需要新增同一脚本、同一 `cap`、同一 seed、同一 observation 策略并统一为完整 forward 计时的测试。
