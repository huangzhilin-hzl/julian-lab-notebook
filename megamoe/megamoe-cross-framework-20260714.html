1. 结论

MegaMoE 目前不是某个统一仓库中的单一实现。公开生态已经分成 DeepGEMM MegaMoE、CuTeDSL MegaMoE，以及 one-sided A2A + 本地 CuTeDSL MoE 的分离式流水三部分。vLLM、SGLang 和 TensorRT-LLM 最早围绕 DeepSeek-V4 接入 DeepGEMM；TensorRT-LLM 又公开了 CuTeDSL MegaMoE；FlashInfer 在 #3852 中开始用统一 MoEEpLayer 同时承载 DeepGEMM 与 CuTeDSL mega backend。
2主要 Mega Kernel 家族：DeepGEMM / CuTeDSL
3主要执行形态：单 Mega Kernel / split pipeline / grouped GEMM primitives
SM90–SM120公开路线覆盖 Hopper、数据中心 Blackwell 与消费级 Blackwell
FP8 / NVFP4 / MXFP4主要激活与权重量化演进方向

2. 概念边界

SGLang #22829 的分离式路线

目标是组合现有最优组件，通信和计算仍有清晰边界，但通过布局复用与 epilogue 融合减少中间步骤。

one-sided NVLink All-to-All → CuTeDSL local MoE → FC2/combine overlap

DeepGEMM / CuTeDSL MegaMoE

使用 symmetric memory 和细粒度调度，把跨 rank dispatch/combine 与专家计算纳入一个长期运行的大 kernel。

dispatch + FC1 + activation + FC2 + combine → one Mega Kernel
